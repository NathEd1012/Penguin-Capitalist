% EmperorPenguin decision structure

%
% Diagram logic:
% BUY: (RSI BUY OR BB BUY) AND (HIGH KER OR HIGH TREND QUALITY)
% Position sizing uses a TRAINABLE cash fraction and a threshold-dependent strength multiplier.
% The final share quantity is calculated, not a separate searched parameter.
% qty = floor(cash * max_cash_fraction * strength / ask)
% strength = min(2.0, max(0.25, KER / ker_entry_threshold, trend_score / trend_entry_threshold))
% max_cash_fraction, ker_entry_threshold, and trend_entry_threshold are searched; the 2.0 cap is fixed.
% The left column shows conceptual BUY gates; the code evaluates SELL first,
% then checks cooldown before evaluating BUY conditions and sizing.
% A BUY or SELL signal resets the per-symbol cooldown; SELL is never blocked by cooldown.
% Both conditional SELL paths reuse the same weakness thresholds:
% HIGH KER = KER >= ker_entry_threshold; WEAK KER = KER < ker_reversal_threshold.
% WEAK TREND QUALITY = trend_score < trend_reversal_threshold.
% Purple frames indicate KER and Trend Quality indicator conditions.
% SELL: Independent or Conditional.
% Independent = STOP LOSS OR TAKE PROFIT OR REL PERFORMANCE.
% Conditional is a SINGLE section with TWO distinct paths:
%   (1) ((RSI SELL OR BB SELL) AND (WEAK KER OR WEAK TREND QUALITY))
%   (2) (RVOL SELL AND ((WEAK KER AND FALLING KER)
%                   OR (WEAK TREND QUALITY AND FALLING TREND QUALITY)))
% The two paths are linked only by the final SELL OR gate.
